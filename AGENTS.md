# AGENTS.md

Everything about this project lives in **Memo, project #22 (wp-base)**: what it is, the rules for working on it, architecture, decisions, open tasks and known issues. This file only tells you how to get there.

1. **Start** with `memo_structure` for project 22. It gives you the card, the map of halls and rooms, and the protocol.
2. **Before deciding anything**, search with `memo_find`, narrowing by hall and room. Working rules are in the `agreements` hall. What is left to do is in `tasks` / `issues` at stage `open`, `doing` or `blocked`.
3. **After every finished task**, update Memo, not Markdown files:
   - new decisions and facts;
   - task and issue stages;
   - `superseded` / `outdated` for what your work replaced.
4. **Before a context compaction**, write the current status as a task in hall `tasks`, room `compaction`. After compaction, read it first, continue from it and close it. There is no STATUS.md.
5. Work only with project #22. If the Memo tools are unavailable, tell the user instead of working from guesses.

The pre-Memo versions of this file and README.md are in git history at `f0ac316`. They are archive material, not instructions.
